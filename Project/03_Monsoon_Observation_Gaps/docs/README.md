## 🖼️ Figure Details

### fig1_roi_map.png
- **Location:** Dakshin Surma Upazila, Sylhet District, Bangladesh
- **Coordinates:** 15°31'44.3"N to 15°31'12.3"N, 91°55'44.5"E to 91°54'36.8"E
- **Area:** ~15.11 km²
- **Type:** T. Aman rice plain (non-haor)
- **Shows:** ROI boundary, surrounding context, cropland extent

### fig2_workflow.png
- **Content:** Flowchart showing:
  1. Study area definition (ROI + cropland mask)
  2. GEE processing pipeline (cloud detection → NDVI calculation)
  3. Python analysis workflow (4 sequential notebooks)
  4. Output generation (CSVs + visualizations)

### fig3_monthly_availability.png
- **X-axis:** Months (June–December, averaged across 2022–2024)
- **Y-axis:** Number of valid observations
- **Series:** Separate bars/lines for each threshold (50%, 60%, 70%, 80%, 90%)
- **Key insight:** Monsoon months (July–September) show lowest availability

### fig4_valid_ndvi_scatter_plot.png
- **X-axis:** Clear cropland pixel percentage (%)
- **Y-axis:** NDVI median value
- **Points:** All 126 Sentinel-2 acquisitions
- **Color coding:** Valid (≥50% threshold) vs. Invalid (<50% threshold)
- **Key insight:** Positive correlation between clear pixels and NDVI

### fig5_gap_distribution.png
- **X-axis:** Gap length (days)
- **Y-axis:** Frequency (count of gaps)
- **Categories:** 
  - 0–5 days
  - 6–10 days
  - 11–15 days
  - 16–20 days
  - 21–30 days
  - >30 days
- **Key insight:** Most gaps are short (5–15 days), but 2023 has one extreme 55-day gap

### fig6_sensitivity.png
- **X-axis:** Validity threshold (50%, 60%, 70%, 80%, 90%)
- **Y-axis:** Observation availability (%) or count
- **Shows:** Inverse relationship between quality threshold and data availability
- **Key insight:** Choosing 90% threshold reduces availability to 25.40%
