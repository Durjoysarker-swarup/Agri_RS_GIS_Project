This folder contains the complete analysis pipeline for the Monsoon Observation Gaps project, organized in three sequential stages.

```

```

## 🚀 How to Run the Complete Pipeline

### Step 1: Understand Study Design
**Folder:** `01_define_observation_system/`

Read `01_define_observation_system/README.md` to understand:
- Why Dakshin Surma (not haor region)
- Why June–December season
- Why years 2022–2024
- Why thresholds 50%–90%
- Data specifications (Sentinel-2, cloud detection, etc.)

**No code to run** — this is documentation of decisions made *before* analysis.

---

### Step 2: Run Google Earth Engine Script
**Folder:** `02_gee_scripts/`

**Prerequisites:**
- Google Earth Engine account (free, requires sign-up at https://earthengine.google.com)
- No local software needed

**Instructions:**
1. Open Google Earth Engine Code Editor: https://code.earthengine.google.com
2. Copy entire contents of `02_gee_scripts/01_main_pipeline.js`
3. Paste into the Code Editor
4. Click **Run** (wait 1–2 minutes for processing)
5. Check **Console** for summary statistics
6. Go to **Tasks** tab → click **Run** to export CSV
7. Download exported CSV: `sylhet_aman_observations_2022_2024.csv`
8. Place CSV in `03_python_analysis/data/raw/`

**Output:**
- CSV file with 126 rows (one per Sentinel-2 acquisition)
- Columns: date, year, month, doy, spacecraft, clear_pixels, clear_pct, total_cropland_pixels, ndvi_median, ndvi_mean

---

### Step 3: Run Python Analysis (Sequential)
**Folder:** `03_python_analysis/`

**Prerequisites:**
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**Run notebooks in order:** 01 → 02 → 03 → 04

Each notebook:
- Reads outputs from previous notebook
- Performs analysis
- Saves results to `data/processed/`

#### Notebook 01: Data Quality & Availability
```bash
jupyter notebook 01_data_quality_availability.ipynb
```
- Loads raw CSV from GEE
- Validates dates, counts observations per year
- Identifies duplicate acquisition dates
- Outputs: `observations_clean.csv`

#### Notebook 02: Valid Observation Classification
```bash
jupyter notebook 02_valid_observation_classification.ipynb
```
- Classifies observations at thresholds 50%, 60%, 70%, 80%, 90%
- Calculates monthly availability
- Outputs: `overall_availability.csv`, `seasonal_monthly_availability.csv`

#### Notebook 03: Gap Detection Analysis
```bash
jupyter notebook 03_gap_detection_analysis.ipynb
```
- Detects gaps between consecutive valid observations
- Computes statistics by year & threshold
- Identifies maximum gap: 55 days (June 5–July 30, 2023)
- Outputs: `gap_distribution.csv`, `gap_overall_summary.csv`

#### Notebook 04: Observed vs. Missing NDVI
```bash
jupyter notebook 04_observed_vs_missing_ndvi.ipynb
```
- Quantifies observation loss at 50% threshold
- Generates threshold sensitivity curve
- Outputs: `threshold_sensitivity.csv`

## ⚠️ Troubleshooting

### GEE Script Fails:
- Verify Google Earth Engine account is active
- Check ROI polygon (`roi.geojson`) is valid
- Ensure Sentinel-2 imagery available for date range

### Python Notebooks Error:
- Confirm CSV placed in correct path: `data/raw/sylhet_aman_observations_2022_2024.csv`
- Run notebooks **in order** (01 → 02 → 03 → 04)
- Check all required libraries installed: `pip list`

### Missing Output Files:
- Verify notebook completed (check for ✅ cells)
- Files saved to `data/processed/` automatically
- Check folder permissions (write access needed)
